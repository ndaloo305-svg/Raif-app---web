# RAIF Web

واجهة ويب أولية مستقلة لمشروع RAIF، بواجهة عربية RTL وتصميم داكن متجاوب.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً ثابتاً:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الموجود حالياً
- واجهة رئيسية متجاوبة.
- بحث محلي وتصفية للأفلام والمسلسلات والأنمي.
- نافذة تفاصيل تجريبية.
- بيانات وهمية لاختبار الواجهة فقط.

## غير المنفذ بعد
- لا توجد قاعدة بيانات أو حسابات مستخدمين.
- لا توجد إضافات Stremio أو مصادر بث أو Torrent أو HTTP/HTTPS مربوطة.
- لا توجد مفاتيح API أو بيانات إنتاجية.
- لم يتم تفعيل النشر الحي بعد.

هذا المستودع منفصل عن تطبيق RAIF iOS. تتم إضافة الربط والخدمات بعد تحديد مصدر البيانات والواجهات البرمجية المطلوبة.
